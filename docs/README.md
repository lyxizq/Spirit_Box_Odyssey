# 灵匣纪元 · Spirit Box Odyssey

一个**完全免费**的放置开箱 H5 修仙游戏。点开灵匣掉装备、堆战力、反哺收益；秘境征战、故事主线、飞升轮回一条龙；注册账号后进度云端同步，还能上战力榜、打竞技场、入仙盟、讨妖王。服务端 Node 零依赖 + SQLite，单机玩法的爽快与多人玩法的长线都在一个页面里。

## 运行

需要 Node.js ≥ 22.5（推荐 24.x；22.5–22.12 需加 `--experimental-sqlite`）。零第三方依赖，无需 `npm install`：

```bash
node server/index.js
# 或：npm start
```

浏览器打开 <http://localhost:8080>，注册道号（2–16 位中文/英文/数字/下划线）登录即玩。可选环境变量：`PORT`（端口，默认 8080）、`DB_PATH`（SQLite 文件，默认 `data/game.db`，已 gitignore）、`ORIGIN_TOKEN`（回源密钥鉴权，部署时用，见 DEPLOY.md）。

直接双击 `index.html` 无法游玩：账号与云存档必须经服务端，请用上面的方式启动。

## 核心循环

1. 开箱（手点/空格/自动/连开十次）掉装备与灵石，攒修为突破境界；境界越高单次收益越高，偶尔开出聚气丹享受 30 秒双倍。
2. 装备进背包（基础 100 格，乾坤扩容符每张 +20、封顶 300 格），穿戴后战力上升；灵石收益带战力乘区 `1 + √战力 ÷ 20`（平方根软压，后期收敛）。
3. 部位强化绑槽位永久生效（十二槽各自 0…+200，每级 +18%，换装不丢）；装备可洗练词条、镶嵌宝石、套装件可吞噬升星。
4. 战力撑起来后去「征战」推秘境，拿开匣得不到的专属套装与战利品，战技再喂战力。
5. 灵石富余后买淬炼、洞府、功法、灵宠、牧场与坊市经营，参与日常与天下玩法，最后满境攒够首飞 1000 亿（此后每次 +1000 亿）灵石飞升换仙缘，滚雪球进入下一轮。

- 仙盟：50,000 灵石立盟，最多 30 人；捐献基金升盟等级（每级全局收益 +0.5%，上限 10 级）；盟任务每日三项（盟库充盈/共讨妖君/切磋砥砺，服务端按真实行为算进度）；盟主妖王每盟每日一只；贡献商店换灵石/碎屑/招募券/洗练券/护体符；同门互助每日可向一位盟友传功、赠礼各一次，双方各得 300 万灵石 + 修为 / 20 碎屑

**账号与安全**
- 注册登录（scrypt 口令哈希）、会话 Cookie（HttpOnly/Secure/SameSite）、连续失败锁定（指数退避）、按 IP/账号滑窗限流、登录假哈希防用户枚举、Origin 同源校验、回源密钥鉴权（ORIGIN_TOKEN，可选）
- 云存档自动同步 + OPFS 本地备份自愈；多标签页写入锁；连点器递进锁定；调试钩子仅限本机
- 服务端反作弊：存档增速账本（累计收益 / 开箱数 / 仙位轮回的单调性与增速校验，违规档拒收）、竞技场胜负与妖王伤害服务端复算、大额领奖统一走 `/api/claim` 授权（27 类领奖 + 天道录 31 梯服务端复核，120 次/分限流）、灵宠捕捉/合成/洗髓概率全在服务端且 uid 服务端发号、云来坊市全服务端权威（原料入账墙钟防伪）、征战胜场素材掉落服务端裁定、灵石类花费（加购 / 立盟 / 捐献）凭账本余额校验
- 手机 / 桌面自适应，明暗主题与字号调节，页脚显示服务端版本号与服务器时间

## 秘境征战

| 玩法 | 规模 | 解锁 | 首领 | 战利品 |
|---|---|---|---|---|
| 闯关 | 200 关 | 开局 | 每 5 关 | 战功 |
| 爬塔 | 200 层 | 通关闯关第 5 关 | 每 10 层 | 塔印 |
| 野外 | 200 区 | 通关闯关第 3 关 | 每 4 区 + 最终区 | 兽骨 |
| 无尽 | 无限层 | 通关爬塔 60 层 | 每 10 层 | 塔印（掉镇塔件） |

- 套装件掉落：四模式统一随机 0.8%/场（首通/复战/扫荡/离线巡猎均计）；另**每胜 50 场保底 1 件**（滚动计数，跨会话累计），每玩法每日保底至多 2 件（配额用尽计数挂起，次日第一胜即掉）。
- 无尽秘境每层轮换词缀：坚壁（敌防 ×1.6）/ 狂暴（敌攻 ×1.35）/ 厚血（敌血 ×1.5）。
- 敌人属性按层数指数增长：`需求战力 = reqBase × reqGrowth^(层-1)`（闯关 15×1.38、爬塔 60×1.16、野外 30×1.90），首领再乘血/攻加成；界面「建议战力」是首领 ×1.35 的参考值。
- 战利品升级三系战技（上限 200 级）：战意（塔印）攻击 +3%/级、体魄（战功）生命 +3%/级、破甲（兽骨）无视防御 +1.5%/级。

### 故事模式「红尘录」

三十卷一百五十关的仙侠主线：每卷对应一个境界门槛，每关另有建议战力；剧情关看对话推进，战斗关走统一战斗结算。通关掉灵石/碎屑并解锁人物立绘，人物志页面可回顾已登场角色。红尘再启四件套：

- **同行助战**：战斗关可从已结识角色中选一名同行，按定位词条给战斗/奖励加成（攻其锋/愈其身/固其盾/增其识/饫其囊）；人物志详情弹层赠礼升好感（5 级），加成随好感成长。乘区只在红尘录战斗内生效，不影响服务端复算的其他战斗。
- **卷末抉择**：每卷末关剧情后一次善恶岔口，选择改动果报（±，影响赌石/洗练/璞玉运气），一次性入档；累计阵营达成隐藏称号「赤子之心」「亦正亦魔」。
- **红尘手札**：残页随关集齐，全卷通关成册（发小赏）并可阅读该卷世界观短文；30 卷全收集达成「红尘笔匠」。
- **隐藏关「尘缘未了」**：每卷一关，本卷全通且同卷人物全结识后开放；首通大赏（灵石部分经 `/api/claim` 服务端复核数额与战力门槛，终身一次），30 关全清达成「尘缘尽览」。

### 天下玩法

以服务端数据为准（切到天下页自动拉取，15 秒内不重发）：

- **战力榜** `/api/rank`：存档同步时自动上报战力与境界，服务端钳制量级后入库
- **竞技场** `/api/pvp`：按评分就近匹配（含「剑影」假人），客户端模拟战斗、服务端校验后 Elo 记分；每日 15 场、可灵石加购 10 次、同一对手每日 3 场、挑战间隔 3 秒
- **天梯榜** `/api/ladder`：评分/胜负/盟名一览，假人常驻
- **回忆之战** `/api/memory`：每周一名红尘录旧首领按周键种子全服轮换（倍率 1.6–2.2 周轮换），敌人以自身 PvP 快照缩放、胜负服务端复算；每人每周一战（`users.memory_week` 防重打），战胜周赏服务端直发账本 + 授权流水
- **世界妖王** `/api/boss`：血量 = 到访时全服最高战力 × 800（2 千万–1 万亿封顶），每人每日 30 击，讨平后参与者与击杀者按日发奖
- **仙盟** `/api/guild`：立盟/入盟/退盟/踢人/公告/捐献（每日上限 10 万灵石，每 2000 灵石 +1 贡献，扣款与记账同事务）；盟任务每日三项（服务端从捐献/盟妖王伤害/切磋场次聚合进度，每项奖励 2 万灵石 + 25 贡献，赏格 2026-11-05 起服务端直发账本 + action_log 授权流水，客户端平加响应实额）；盟主妖王每人每日 5 击、每 5000 伤害 +1 贡献；贡献商店每日限购，可换灵石俸禄/碎屑/招募券/洗练券/护体符；同门互助 `/api/guild/aid`（传功/赠礼每日各一次，服务端记账、双方受益）；仙盟共修 `/api/guild/cult`：盟员每日捐 20 万灵石 ×3 次充盈当日盟池（账本原子扣款），盟池达 60 万/200 万/500 万三档全盟可领（每人每档一次，直发 30 万/80 万/200 万灵石 + 30/60/100 碎屑，`guild_cult*` 三表记账），领奖当日「共修心得」灵石与碎屑收益 +3%

- **洞府访客** `/api/visitor`：每日一位访客按（日期 + uid）种子确定性推导，三选一互动（切磋/赠礼/求教）服务端裁定直发账本 + 授权流水，每人每日一次（`visitor_acts` 表防重）

## 部署

服务端是单进程 Node 应用（零依赖），任何能跑 Node ≥ 22.5 的机器都行：

```bash
PORT=80 DB_PATH=/var/lib/lingxia/game.db node server/index.js
```

要对外发布时也可以先打混淆部署包（`npm run build:deploy`，产出 `dist/spirit-box-odyssey-deploy/` 与同名 zip，前端 JS 混淆、CSS/HTML 压缩，包内 `package.json` 已剥离构建依赖，解压后照常 `npm start`）。

**宝塔面板安装 + 腾讯 EdgeOne 接入 + 锁源 + 备份运维的完整步骤见 [DEPLOY.md](DEPLOY.md)。**要点：游戏端口不对公网开放，只放行 EdgeOne 回源网段（付费）或启用 `ORIGIN_TOKEN` 回源密钥（免费版）；Nginx 反代必须传 `X-Forwarded-For`；HTTPS 下会话 Cookie 自动加 `Secure`。

常用公式（`game.js` 内同名函数）：

```js
const interval = () => Math.max(0.2, 2.5 * Math.pow(0.95, state.speedLv));

// 灵石收益：逐项乘区（境界/仙缘/战力/收集/宠物/洞府/仙位/称号/陈列/修行/时辰/道侣/仙盟/丹药）
const baseGain = () => (3 + 0.9 * state.gainLv) * realmMult()
  * prestigeMult()   // 仙缘：1 + 0.05 × 飞升次数
  * powerMult()      // 战力：1 + √战力 / 20
  * /* 其余乘区见 game.js */;

// 装备战力只含装备自身（基础 × 升星）；部位强化乘区挂 totalPower（换装不丢，每级 +18%）
const itemPower = (it) => Math.round(it.power * (1 + 0.1 * (it.star || 0)));

// 战斗：战力 → 攻防血，再乘境界、仙缘（攻血 +8%/次）、装备等级词条宝石、套装与战技
atk = (16 + power * 0.9) * (1 + 0.12 * realm) * 词条攻加成;
hp  = (120 + power * 5.5) * (1 + 0.15 * realm) * 词条血加成;
def = (3 + power * 0.28) * (1 + 0.10 * realm) * 词条防加成;

// 敌人基准：层数越高指数增长
const contentReq = (mode, level) => reqBase * Math.pow(reqGrowth, level - 1);
```

天下玩法的服务端数值（妖王血量系数、每日次数、Elo、盟等级等）在 `server/social.js` 顶部常量区；坊市（建筑/配方/订单/商誉）在 `server/shop.js`，灵宠概率在 `server/pets.js`。

## 存档

- **云端为主**：登录后进度自动同步到服务端 SQLite（`game_saves` 表，每用户一行），节流推送（约 5 秒级），关页 `sendBeacon` 兜底推最后一帧；服务端逐字段校验量级（realm 0–9、灵石/碎屑/修为/战力上限等），伪造档直接 400
- **WebSocket 长连接** `/api/ws`（2026-11-04 起）：登录后建立 `wss://` 长连接——存档帧与 HTTP POST 走**同一条**校验/账本/包络管线（零依赖 RFC6455 实现，`server/ws.js`），服务端每 60 秒心跳推时间/体力/悬赏妖踪快照（WS 在线时 HTTP 轮询心跳停跑），断线自动回退 HTTP 轮询、连续握手失败禁用本会话；同源 + 会话 Cookie 鉴权、单会话单连接（新连踢旧）、客户端帧强制掩码、帧上限 512KB
- **云端唯一持久层（2026-10-31）**：进度只存服务端 SQLite，浏览器不再落本地存档（localStorage/OPFS 均已移除）；启动拉云端档入局，拉取失败/档损坏会拦下启动而非拿空白档开局。正常关页有 sendBeacon 兜底推最后一帧，服务器宕机/断网期间强关页面可能丢最近几秒进度
- 换设备登录同一账号自动恢复；「设置 → 存档」的重置会同时清云端档与增速账本（`POST /api/reset`），下次进游戏全新开局
- 存档字段全景见 [HANDOFF.md](HANDOFF.md)；多标签页只建议开一个，后开标签页的本地写入会被暂停以免互相覆盖
- 页脚显示服务端版本号与服务器时间（按服务器时区走针；HTTP `/api/version` 每 10 分钟校准，WS 在线时由 60 秒时间帧校准并带时区真值）；顶栏右侧是道号与退出登录
