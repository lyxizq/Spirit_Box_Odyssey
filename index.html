          玩法说明

          核心循环

          开灵匣得装备 / 灵石 / 修为 → 灵石淬炼提速提收益 → 修为突破境界 → 境界解锁新玩法 → 征战打更强的怪、拿更好的装备，滚雪球成长。

          修炼 · 境界与飞升

          开箱产修为；修为够即突破境界（炼气→筑基→…→仙人）。仙人后可飞升（轮回）：重置灵石 / 境界 / 淬炼，换仙缘永久收益与更高的境界门槛。挑战修行在飞升时达成即记功。

          征战 · 四大秘境

          闯关起点玩法，5 关一首领；爬塔 200 层产镇塔套；野外刷材料与荒狩套；无尽无限层带词缀，通塔 60 层开启。首通里程碑必掉专属套装件。试炼区另有探幽 / 首领连战 / 条件试炼 / 悬赏令（白绿蓝紫四单，全清加奖）与异象秘境（每日双词缀 boss，按余血评 S/A/B 级，S 级 5% 掉仙品）。

          装备

          六部位（武器/衣袍/冠冕/云靴/法宝/灵符），品质白→绿→蓝→紫→金→仙。强化（+200）与升星加成；词条与宝石在工坊洗练镶嵌；符文组词按宝石顺序触发；套装凑件数有额外效果。炼器用器魂定向打造天品。

          养成系统

          战技（塔印/战功/兽骨升级）、功法（修为参悟）、灵宠（出战加成+内丹特性）、道侣（好感永久加成）、丹药 / 洞府 / 淬炼——这些点击升级是战力主通道。

          日常与闲趣

          签到二选一：普通签到稳拿当日奖，或赌狗签到押上当日奖励掷倍率——49% 狂赚 ×2~5、10% 保本 ×1、20% 空手、21% 倒扣 1~3 倍（灵石可扣成负债，碎屑扣到 0 为止，量力而赌）；战绩面板记流水。月度朝贺按月记到勤，缺勤可补签。日活福利：灵潮双时段（12–14 / 20–22 点）产出 ×2、每日占卜一签定运势、在线每 60 分钟聚一格灵气、仙道问答每日十题。日常 / 周常领奖；黑市限购与赌石；垂钓、灵圃采集、秘境图探雾、藏宝图挖宝、云游奇遇（冷却到点页顶横幅提示）。

          天下 · 玩家玩法

          竞技场每日 15 场可灵石加购，胜负动天梯分；世界妖王全服共血条；仙盟捐献 / 盟任务 / 盟妖王 / 贡献商店 / 同门互助（每日传功赠礼各一次，双方受益）。

          战斗规则

          回合制自动对战：伤害 = 攻 − 防×(1−破甲)，暴击 ×1.75，吸血按伤害回血，120 回合未分胜负判超时。战败不损失进度。

          存档
