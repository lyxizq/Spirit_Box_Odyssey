          玩法说明

          核心循环

          开灵匣得装备 / 灵石 / 修为 → 灵石淬炼提速提收益 → 修为突破境界 → 境界解锁新玩法 → 征战打更强的怪、拿更好的装备，滚雪球成长。

          修炼 · 境界与飞升

          开箱产修为；修为够即突破境界（炼气→筑基→…→仙人）。仙人后攒 1000 亿灵石可飞升（轮回）：散尽灵石、重置境界与淬炼，换 1 点仙缘（灵石收益 +5%、修为 +50%，可叠加）；飞升前有四栏确认弹层交代归零 / 保留 / 新玩法 / 增益。挑战修行在飞升时达成即记功。闭关打坐（筑基）选时长入定，香火抬修为，出关结算大额修为（15% 顿悟翻倍、10% 走火入魔引心魔），入定期间开箱修为减半；五行道基（金丹）择五行凝道基逐阶永久乘区，升阶吞同五行装备，每世金丹可免费改道；道童历练（渡劫）派道童远行带回钱粮素材与见闻，见闻喂道童资质解锁自动续关 / 长差 / 星河渡口；道悟星图（元婴）开箱凝道韵点亮 30 星逐星加成，飞升布点归元返还。

          征战 · 四大秘境

          闯关起点玩法，5 关一首领；爬塔 200 层产镇塔套；野外刷材料与荒狩套；无尽无限层带词缀，通塔 60 层开启。套装部件 0.8%/场随机掉落，另每胜 50 场保底 1 件（每玩法每日至多 2 件）；胜场还可能掉牧场种子与洗炼石。试炼区另有探幽 / 首领连战 / 条件试炼 / 悬赏令（白绿蓝紫四单，全清加奖）与异象秘境（每日双词缀 boss，按余血评 S/A/B 级，S 级 5% 掉仙品）。

          装备

          十二部位（武器/衣袍/冠冕/云靴/护腿/护腕/手镯/戒指/法宝/灵符/发箍/翅膀），品质凡品→灵品→玄品→地品→天品→仙品六档。装备带等级：掉落瞬间随境界定级，飞升归 0 重爬。部位强化（+200，绑槽位换装不丢）与升星加成；词条与宝石在工坊洗练镶嵌（洗练另耗六型洗炼石）；符文组词按宝石顺序触发；套装凑件数有额外效果。炼器用器魂定向打造天品；熔铸十件地品熔天品、五件天品熔仙品（70%±10%）。

          养成系统

          战技（塔印/战功/兽骨升级）、功法（修为参悟）、灵宠（缚灵谷捕捉个体出战，天赋+词条加成）、道侣（好感永久加成）、丹药 / 洞府（含云坊）/ 淬炼——这些点击升级是战力主通道。

          经营 · 牧场与坊市

          方格牧场：12×12 格地四向开垦，七种种子 30 分钟～8 小时成熟，收获掉碎屑、洗炼石与随机种子；云来坊市（金丹解锁）：牧场 / 灵圃收获自动入仓，丹房 / 器坊 / 符箓铺制作成品，直售兜底或接订单（1.8 倍溢价 + 商誉），商誉解锁新建筑。

          日常与闲趣

          签到二选一：普通签到稳拿当日奖，或赌狗签到押上当日奖励掷倍率——49% 狂赚 ×2~5、10% 保本 ×1、20% 空手、21% 倒扣 1~3 倍（灵石可扣成负债，碎屑扣到 0 为止，量力而赌）；战绩面板记流水。月度朝贺按月记到勤，缺勤可补签。日活福利：灵潮双时段（12–14 / 20–22 点）产出 ×2、每日占卜一签定运势、在线每 60 分钟聚一格灵气、仙道问答每日十题。日常 / 周常领奖；黑市限购与赌石；垂钓（十钓场 200 种鱼，每场一条可化形赠宝的龙鱼；竿等逐场解封，每日赠 50 枚鱼饵、饵尽 5000 灵石/竿，钓到点亮渔获图鉴，渔获附带草籽 / 洗炼石）、灵圃采集、秘境图探雾、藏宝图挖宝、云游奇遇（60 种事件，善恶改果报，冷却到点页顶横幅提示）。

          天下 · 玩家玩法

          竞技场每日 15 场可灵石加购，胜负动天梯分；天梯日俸按段位每日领俸（打过一场即解锁）；悬赏妖踪每日三只妖将按你的实力现身，各战一场、战胜得赏；回忆之战每周一位红尘录旧首领，战胜得周赏；世界妖王全服共血条；仙盟捐献 / 盟任务 / 盟妖王 / 贡献商店 / 同门互助（每日传功赠礼各一次，双方受益）。显示名、盟名、盟公告等一切输入文本均过屏蔽词校验，含屏蔽词会被拒绝。

          战斗规则

          回合制自动对战：伤害 = 攻 − 防×(1−破甲)，暴击 ×1.75，吸血按伤害回血，120 回合未分胜负判超时。战败不损失进度。
