# 灵匣纪元 · Spirit Box Odyssey

一个**完全免费、纯前端**的放置开箱 H5 小游戏原型。开箱掉装备、进背包、穿戴、强化、堆战力，再用战力反哺灵石收益；另有爬塔、闯关、野外三套秘境征战，产出开匣得不到的专属套装。全部本地运行，不需要服务器、数据库或任何第三方素材。

> 这是原创 Demo，不是「无双纪」「蓬莱修仙」的换皮包，也不包含任何第三方游戏素材或代码。想商用请自行替换文案、美术并做合规评估。

## 运行

```bash
cd 默认项目
python3 -m http.server 8080
```

浏览器打开 <http://localhost:8080>。

直接双击 `index.html` 也能玩，但部分浏览器对 `file://` 的本地存储限制较严，建议用上面的本地服务器。

## 已实现

- 自动开箱 + 手动开箱 + 连开十次
- 6 档品质（凡 / 灵 / 玄 / 地 / 天 / 仙），带掉率权重和颜色
- **6 个装备部位**：武器、衣袍、冠冕、云靴、法宝、灵符
- **60 格背包**：掉落不再自动分解，可穿戴、卸下、单件分解
- **战力系统**：已穿戴装备的战力总和越高，灵石收益倍率越高
- **强化系统**：已穿戴装备可强化至 +20，每级 +18% 基础战力
- **一键穿戴 / 分解低品 / 清空分解**；背包满时才自动保留更强的一件
- 灵石收益、开箱速度、气运三条升级线
- 10 个境界（炼气 → 仙人），突破永久加收益
- 暴击 5% ×10、聚气丹 30 秒双倍
- 离线收益（最多 4 小时，50% 效率，只结算灵石与修为）
- **秘境征战**：闯关 30 关、爬塔 60 层、野外 12 区，逐层递增难度
- **专属套装**：镇塔 / 征伐 / 荒狩三套 6 件套，只能从秘境掉落，开匣不出
- **首领与首通奖励**：塔每 10 层、关每 5 关、野外每 4 区出首领
- **战利品与战技**：塔印 / 战功 / 兽骨，升级战意、体魄、破甲
- **战斗弹窗**：双方头像、血条、攻击动画、逐回合日志、跳过与回看
- **自动巡猎**：野外可挂机刷怪，不弹窗；手动战斗会暂停巡猎
- 最近掉落、图鉴、最高品质记录
- `localStorage` 自动存档、手动重置、音效开关
- 手机 / 桌面自适应，键盘空格可开箱

## 玩法说明

1. 每次开箱都会掉一件装备，随机部位、品质和基础战力。
2. 装备先进入背包，**平时不会自动分解**；点「穿戴」替换当前部位，旧装备回到背包。
3. 已穿戴装备可以用灵石强化，强化等级跟着装备走；卸下或替换不会掉级。
4. 总战力每 400 点，灵石收益 +100%（即 `1 + 战力 / 400`，线性叠加）。
5. 背包 60 格。只有装满时，新掉落才会和最弱的一件比较，保留更强的一件，另一件自动分解；灵石照常结算。
6. 飞升保留装备、背包、图鉴和仙缘，只重置灵石、境界和淬炼。
7. 秘境战斗不消耗资源、不损失进度；打不过就回去开箱、强化、升战技。

## 秘境征战

三种玩法共用一套战斗结算：战力转化为攻击 / 生命 / 防御，逐回合互砍，带暴击、吸血、减伤、破甲等套装与战技加成。

| 玩法 | 规模 | 解锁 | 首领 | 首通套装部件 | 战利品 |
|---|---|---|---|---|---|
| 闯关 | 30 关 | 默认开放 | 每 5 关 | 5 / 10 / 15 / 20 / 25 / 30 关 | 战功 |
| 爬塔 | 60 层 | 通关闯关第 5 关 | 每 10 层 | 10 / 20 / 30 / 40 / 50 / 60 层 | 塔印 |
| 野外 | 12 区 | 通关闯关第 3 关 | 每 4 区 + 最终区 | 1 / 3 / 5 / 7 / 9 / 11 区 | 兽骨 |

### 递增难度

敌人基准值按层数指数增长：

```js
contentReq(mode, level) = reqBase * reqGrowth ** (level - 1)

// 闯关
reqBase = 15,  reqGrowth = 1.38,  HP ×7.2,  ATK ×0.72, DEF ×0.20
// 爬塔
reqBase = 60,  reqGrowth = 1.16,  HP ×7.5,  ATK ×0.75, DEF ×0.22
// 野外
reqBase = 30,  reqGrowth = 1.90,  HP ×6.8,  ATK ×0.68, DEF ×0.18
```

首领额外加成：闯关 HP ×1.4 / ATK ×1.18，爬塔 HP ×1.45 / ATK ×1.2，野外 HP ×1.3 / ATK ×1.12，防御统一 ×1.12。界面上的「建议战力」为首领再乘 1.35 的参考值。

### 专属套装

三套均为 6 件套，基础战力随掉落层数提高，**不会从灵匣掉落**：

| 套装 | 来源 | 2 件 | 4 件 | 6 件 |
|---|---|---|---|---|
| 镇塔 | 爬塔 | 防御 +30% | 生命 +30% | 受到伤害 -15% |
| 征伐 | 闯关 | 攻击 +20% | 暴击率 +8% | 攻击 +35% |
| 荒狩 | 野外 | 生命 +20% | 攻击 +15% | 攻击吸血 12% |

- 首通里程碑必掉指定部位；野外重复狩猎每 12 杀必掉一件，另有 6% 随机掉落。
- 爬塔 / 闯关通关最终层后进入再战模式，奖励减半，仍有 8% 概率掉套装。
- 特殊装备使用独立强化费用，强化上限同为 +20；背包满时同样自动保留更强的一件。

### 战利品与战技

- 每次胜利获得对应战利品：层数越高、首领、首通都会额外增加。
- 战意（塔印）：攻击 +3% / 级。
- 体魄（战功）：生命 +3% / 级。
- 破甲（兽骨）：无视敌人防御 +1.5% / 级。
- 三项战技上限均为 10 级。

### 战斗表现

- 手动挑战会弹出战斗层：双方头像、血条、突进与受击动画、伤害飘字、逐回合日志。
- 日志记录每回合出手、暴击与吸血；结束后显示回合数、总伤害、奖励和掉落。
- 支持「跳过动画」、点击遮罩关闭、战斗结束后「回看战报」。
- 野外「自动巡猎」每 3 秒结算一场，不弹窗，只在面板内更新战报；手动挑战会暂停巡猎。
- 每个玩法各自保留最近一场战报，刷新页面后清空（进度与奖励已存档）。

## 部署

三个静态文件，扔到任何静态托管即可：

- GitHub Pages
- Cloudflare Pages
- Vercel / Netlify
- 自己的 Nginx / 宝塔站点

Nginx 示例：

```nginx
server {
    listen 80;
    server_name game.example.com;
    root /www/wwwroot/lingxia;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

H5 外网访问建议配 HTTPS；微信内打开需要域名备案。

## 改数值

都在 `game.js` 顶部的常量里：

| 常量 | 作用 |
|---|---|
| `RARITIES` | 品质名称、颜色、掉率权重、基础分解价值、修为 |
| `ITEM_NAMES` | 每个部位、每个品质的装备名池 |
| `BASE_POWER` | 各品质装备的基础战力 |
| `SLOTS` | 六个装备部位 |
| `BAG_CAP` | 背包格数（默认 60） |
| `MAX_ENHANCE` | 单件装备强化上限（默认 +20） |
| `TOWER_MAX` / `STAGE_MAX` / `WILD_MAX` | 爬塔层数、闯关关数、野外区域数 |
| `MAX_TRAIN` | 战技等级上限（默认 10） |
| `MODES` | 三种玩法的基准值、成长率、敌人属性倍率、首领加成 |
| `MILESTONES` | 各玩法首通必掉套装部件的层数 |
| `SETS` | 三套专属套装的名称、部件与 2/4/6 件效果 |
| `TROPHIES` / `TRAININGS` | 战利品字段与战技消耗、加成 |
| `REALMS` / `REALM_COSTS` | 境界名称与突破所需修为 |
| `UPGRADES` | 三条升级线的初始价格、价格增长、等级上限 |
| `OFFLINE_CAP` / `OFFLINE_EFF` | 离线结算上限与效率 |
| `CRIT_CHANCE` / `CRIT_MULT` | 暴击率与暴击倍率 |
| `BUFF_CHANCE` / `BUFF_MS` | 丹药掉率与持续时间 |

几个常用公式也在 `game.js` 里：

```js
const interval = () => Math.max(0.25, 2 * Math.pow(0.94, state.speedLv));
const baseGain = () => (3 + 0.9 * state.gainLv) * Math.pow(1.7, state.realm) * (1 + 0.25 * state.ascensions) * (1 + totalPower() / 400);
const itemPower = (it) => Math.round(it.power * (1 + 0.18 * (it.lv || 0)));
const enhanceCost = (it) => it.special
  ? Math.floor((it.power * 2.2 + 30) * Math.pow(1.42, it.lv || 0))
  : Math.floor(RARITIES[it.r].stone * 10 * Math.pow(1.55, it.lv || 0));
const salvageValue = (it) => it.special
  ? Math.floor((it.power * 2 + 20) * (1 + 0.35 * (it.lv || 0)))
  : Math.floor(RARITIES[it.r].stone * 2 * (1 + 0.4 * (it.lv || 0)) * (1 + 0.2 * state.gainLv));

// 战斗：战力 → 攻防血，再乘境界、仙缘、套装与战技
atk = (16 + power * 0.9) * (1 + 0.12 * realm) * (1 + 0.08 * ascensions);
hp  = (120 + power * 5.5) * (1 + 0.15 * realm) * (1 + 0.08 * ascensions);
def = (3 + power * 0.28) * (1 + 0.10 * realm);

// 敌人基准：层数越高指数增长
const contentReq = (mode, level) => MODES[mode].reqBase * Math.pow(MODES[mode].reqGrowth, level - 1);
```

## 存档

- Key：`lingxia_idle_v1`
- 存在浏览器 `localStorage`
- 旧版存档会自动补齐背包、装备和物品编号，不会丢境界和升级
- 秘境进度字段：`towerCleared`、`stageCleared`、`wildZone`、`wildCleared`、`wildKills`
- 战利品与战技字段：`towerMarks`、`warMerits`、`beastBones`、`trainAtk`、`trainHp`、`trainPierce`
- `autoHunt` 记录自动巡猎开关；战斗回放只在内存中，刷新后需重新挑战
- 清缓存 / 换浏览器 / 无痕模式会丢档
- 建议只开一个标签页；多标签会同时写同一个 key，进度会互相覆盖
- 想接后端的话，把 `save()` / `load()` 换成接口即可，玩法代码不用动
